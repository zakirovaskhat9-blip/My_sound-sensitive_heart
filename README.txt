КАК ОБНОВИТЬ ПРИЛОЖЕНИЕ И ПОЛУЧИТЬ НОВЫЙ APK

1. Распакуй этот архив на компьютере.
2. Открой свой репозиторий на github.com -> Add file -> Upload files.
3. Выдели ВСЁ содержимое распакованной папки (Ctrl+A) и перетащи в окно браузера
   (папки www, assets, .github и файлы package.json, capacitor.config.json, debug.keystore и остальные).
   Файлы с одинаковыми именами заменятся новыми. Нажми Commit changes.
4. Открой вкладку Actions: сборка запустится сама (3-6 минут).
5. Когда появится зелёная галочка, открой сборку и скачай внизу my-sound-sensitive-heart-apk.
   Внутри лежит app-debug.apk.
6. ВАЖНО, только в этот раз: удали старое приложение с телефона перед установкой нового
   (у него другой ключ подписи). Музыку придётся добавить заново.
   Дальше новые версии будут ставиться поверх старой без удаления, музыка сохранится.
