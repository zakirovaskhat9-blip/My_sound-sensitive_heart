КАК ОБНОВИТЬ ПРИЛОЖЕНИЕ И ПОЛУЧИТЬ НОВЫЙ APK

ШАГ 1. Загрузить файлы
1. Распакуй этот архив (правая кнопка -> Извлечь всё).
2. Открой свой репозиторий на github.com -> Add file -> Upload files.
3. Открой распакованную папку, выдели ВСЁ внутри (Ctrl+A) и перетащи в окно браузера.
   Дождись, пока все файлы загрузятся, и нажми Commit changes.

ШАГ 2. Проверить, что всё на месте
На главной странице репозитория (вкладка Code) должны быть:
  папки:  assets, native, www, .github
  файлы:  package.json, capacitor.config.json, debug.keystore, README.txt
Чего-то нет - загрузи недостающее (Add file -> Upload files).

ШАГ 3. Заменить файл автосборки
1. Открой .github/workflows/build-apk.yml -> значок карандаша (Edit).
2. Выдели весь текст (Ctrl+A), удали, вставь текст из файла build-apk.yml (он лежит рядом с этим архивом).
3. Нажми Commit changes (два раза).
   Если папки .github нет: Add file -> Create new file, в имени напиши
   .github/workflows/build-apk.yml и вставь текст из build-apk.yml.

ШАГ 4. Скачать apk
1. Открой вкладку Actions. Сборка идёт 3-6 минут.
2. Когда появится зелёная галочка, нажми на название сборки.
3. Внизу в разделе Artifacts скачай my-sound-sensitive-heart-apk, распакуй - внутри app-debug.apk.
4. Перекинь на телефон и установи поверх старого приложения (музыка сохранится).

ЕСЛИ СБОРКА УПАЛА (красный крестик)
Нажми на красный запуск -> build -> открой шаг, помеченный красным. Если там написано
"НЕТ ФАЙЛА В РЕПОЗИТОРИИ: ..." - загрузи этот файл. Иначе пришли скриншот ошибки.
